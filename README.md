# FLOOR IS LAVA

Многопользовательская игра на выживание в Roblox. Забирайтесь по меняющейся арене с препятствиями, уворачивайтесь от вращающихся ловушек и спасайтесь от поднимающейся лавы. Побеждает последний выживший.

## Текущая версия

### Игровой процесс
- Раунды запускаются даже при одном реальном игроке: в одиночной игре появляются два лёгких NPC-соперника.
- В многопользовательской игре NPC не появляются, если на сервере находятся два или более реальных игрока.
- Между раундами есть перерыв. Предусмотрены таймер выживания, поднимающаяся лава, определение победителя и возвращение в лобби.
- Генератор процедурно создаёт новую арену для каждого раунда.
- С каждого уровня есть как минимум два доступных варианта подъёма.
- На высоких платформах расположены движущиеся неоновые ловушки.
- Контакт с лавой или ловушкой выводит из раунда как игроков, так и NPC.
- За участие начисляются монеты, победитель получает дополнительную награду.
- Победы и монеты сохраняются через DataStore.
- В лобби отображается глобальный рейтинг десяти лучших игроков по победам (OrderedDataStore, раз в 60 сек).

### Модификаторы раундов
Каждый раунд случайно выбирается один модификатор (с весами):
- **STANDARD** — классический режим
- **FAST LAVA** — лава поднимается быстрее
- **HAZARD HEAVY** — больше вращающихся ловушек
- **NARROW PATHS** — более узкие платформы
- **SKY CLIMB** — дополнительные уровни высоты
- **ASH FOG** — густой вулканический туман

Модификатор объявляется уже во время intermission и отображается на HUD.

### Магазин (монеты)
Кнопка **SHOP** в лобби. Покупки действуют на **следующий** раунд:

| Предмет | Цена | Эффект |
|--------|------|--------|
| Jump Boost | 40 | +12 JumpPower |
| Speed Boost | 30 | +4 WalkSpeed |
| Second Chance | 80 | одно возрождение при падении в лаву |

### Боты
- Выбор цели с небольшой случайностью.
- Отслеживание прогресса по слоям и мягкий anti-stuck (MoveTo → teleport → escalate).
- Параметры в `Config` (`BOT_*`).

### Звуки
В `Config` задаются asset ID (0 = выключено):
`MUSIC_ASSET_ID`, `SOUND_JUMP`, `SOUND_LAVA`, `SOUND_TRAP`, `SOUND_ELIMINATE`, `SOUND_WIN`, `SOUND_SHOP`, `SOUND_ROUND_START`.

Jump SFX: `JumpSFX.client.lua`.

### Модули
- `Shared/Sounds.lua` — общий helper
- `ServerScriptService/Modules/Arena.lua` — генерация арены
- `ServerScriptService/Modules/Bots.lua` — NPC AI
- `GameServer.server.lua` — оркестратор раунда / shop / DataStore

## Установка
1. Rojo + плагин Studio
2. `git clone` / checkout `refactor/modifiers-shop-bots`
3. `rojo serve`
4. Подключить плагин в Studio
5. DataStore: publish + Enable Studio Access to API Services

## Принципы
- Состояние раунда и награды — только на сервере
- Сначала модификаторы и цикл, потом монетизация
