# FLOOR IS LAVA

Многопользовательская игра на выживание в Roblox. Забирайтесь по меняющейся арене с препятствиями, уворачивайтесь от вращающихся ловушек и спасайтесь от поднимающейся лавы. Побеждает последний выживший.

## Текущая версия

### Игровой процесс
- Раунды запускаются даже при одном реальном игроке: в одиночной игре появляются два лёгких NPC-соперника.
- В многопользовательской игре NPC не появляются, если на сервере находятся два или более реальных игрока.
- Между раундами есть перерыв. Предусмотрены таймер выживания, поднимающаяся лава, определение победителя и возвращение в лобби.
- Генератор процедурно создаёт новую арену для каждого раунда. Меняются количество дорожек, направление и смещение маршрутов, высота, размеры и цвета платформ, а также места появления ловушек.
- Платформы образуют разнесённые ступенчатые группы, которые смещаются и немного поворачиваются на каждом уровне. С каждой платформы предусмотрено минимум два перехода на следующий уровень.
- Генератор проверяет зазор между краями платформ (`Config.MAX_EDGE_GAP`, по умолчанию 7.5) и отдельно проверяет первые прыжки со стартовой площадки.
- На высоких платформах расположены движущиеся неоновые ловушки.
- Контакт с лавой или ловушкой выводит из раунда как игроков, так и NPC.
- За участие начисляются монеты, победитель получает дополнительную награду.
- Победы и монеты сохраняются через DataStore; глобальный топ-10 — OrderedDataStore.

### Модификаторы раундов
Случайный модификатор каждый раунд (с весами), объявляется в intermission:
- **STANDARD**, **FAST LAVA**, **HAZARD HEAVY**, **NARROW PATHS**, **SKY CLIMB**, **ASH FOG**

### Магазин
Кнопка **SHOP** в лобби. Баффы на **следующий** раунд:

| Предмет | Цена | Эффект |
|--------|------|--------|
| Jump Boost | 40 | +12 JumpPower |
| Speed Boost | 30 | +4 WalkSpeed |
| Second Chance | 80 | одно возрождение при падении в лаву |

### Боты
- Навигация по rotated pads через edge points в локальных осях платформы.
- Фильтр прыжков по edge gap, jump margin, soft stuck recovery.
- Небольшая случайность выбора цели (`BOT_TARGET_RANDOMNESS`).

### Звуки
ID в `Config` (`SOUND_*`, `MUSIC_ASSET_ID`); `0` = выключено. Jump SFX — `JumpSFX.client.lua`.

## Установка
1. Rojo + плагин Studio  
2. `git clone` → `rojo serve` → connect  
3. DataStore: publish + Enable Studio Access to API Services  

## Что проверять в Studio
- Нет предупреждений `Route validation` / `Start jump is too long`.
- Минимум два перехода с каждой платформы, edge gap ≤ `MAX_EDGE_GAP`.
- Модификатор на intermission и HUD; магазин и Second Chance.
- Боты не застревают надолго; NPC jump margin.
- Награды один раз; HUD читаем на телефоне.

## Принципы
- Композиция, свет, цвет важнее тяжёлых мешей.
- Состояние раунда и награды — на сервере.
- Сначала маршруты и цикл, потом монетизация.
